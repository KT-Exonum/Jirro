# Shader compilation (offline, per Section 3)

Production builds embed pre-compiled SPIR-V; there is no runtime GLSL
compiler in the shipped app.

## One-time bring-up shaders

```sh
glslangValidator -V triangle.vert -o triangle.vert.spv
glslangValidator -V triangle.frag -o triangle.frag.spv

xxd -i triangle.vert.spv > triangle_vert_spirv.inc
xxd -i triangle.frag.spv > triangle_frag_spirv.inc
```

Then replace the zero-length placeholder arrays in
`engine/vulkan/VulkanDevice.cpp` (`generated_shader_bytecode` namespace) with
the generated byte arrays (cast to `const uint32_t[]`, word count = byte
count / 4). `CreateBringUpPipeline()` deliberately fails loudly if this step
hasn't been done, rather than silently rendering nothing.

## Phase 2 video-sampling shader (new)

A fullscreen-blit fragment shader that samples a
`VkSamplerYcbcrConversion`-backed image needs the `GL_EXT_YCbCr_target`-style
combined-image-sampler binding declared with an **immutable sampler** baked
into the descriptor set layout (see
`VulkanDevice::GetOrCreateYcbcrSampler`) — a ycbcr sampler cannot be bound
dynamically like an ordinary sampler2D. The GLSL side is otherwise a normal
`sampler2D` declaration; the conversion happens transparently in the
fixed-function texture unit, so no explicit YUV math is needed in the shader
itself. This lands with Phase 3's DrawFullscreenPass wiring, once a real
pipeline exists to attach the immutable sampler to.

## Phase 3+ shader nodes

User/effect shaders authored as GLSL or HLSL should go through the same
offline pipeline (`glslangValidator` for GLSL, `dxc -spirv` for HLSL) as part
of the project's asset build step, producing `.spv` files bundled as
`assets/shaders/*.spv` and loaded via `GraphicsDevice::CreateShaderModule`.

A dev-only runtime path (guarded by `ENGINE_DEV_SHADER_HOTLOAD`, see
`CMakeLists.txt`) may shell out to `glslangValidator` (via
`shaderc`'s C++ API is preferable to a subprocess on-device) for fast
iteration on shader-node uniforms in the node editor; it must not ship in
release builds.
